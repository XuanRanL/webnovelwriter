# 正文严禁创作术语 / 元叙述泄漏（跨项目永久防御）

> **本文件适用于本插件所有项目**（本插件所有项目）。
> **写任何小说时都必须遵守此规则**。

## 核心原则

**正文是给读者看的小说，不是给作者看的项目笔记**。

任何写作过程中产生的术语、文档名、流程标识、能力体系标签、商业节点、套路定位词，**都不能出现在正文里**。

读者看到这些 = 立刻出戏。编辑看到这些 = 直接判"未清稿"退稿。

## 禁止词全表（共 28 类 · H40 P0 闸门检测）

### A. 章节编号元叙述
- ❌ `Ch1` / `Ch{N}` / `chapter 5` / `第N章`（用作指代而非标题）
- ❌ `Round 22` / `Step 6` / `v7.1`
- ✅ 用具体事件描述："重生第一天" / "他们在日料店那一夜" / "上礼拜在主火山口"

### B. 能力体系创作术语
- ❌ `金手指` 
- ❌ `工具人`
- ✅ 用"那一份能力" / "那一份" / 直接写她做了什么

### C. 结构钩子术语
- ❌ `仇恨钩` / `情感钩` / `信息钩` / `危机钩` / `追读钩` / `开篇钩` / `章末钩` / `第一钩`
- ✅ 用人物内心或场景描写

### D. 升级修辞
- ❌ `大爆破` / `爆点章` / `高潮章`（在正文里指代本章）
- ✅ 用具体描写："这是一次质变" / "屋顶被一下掀起来"

### E. 商业 / 伏笔 meta
- ❌ `承诺兑现` / `签约节点` / `2 万字签约` / `5 万字推荐`
- ❌ `伏笔回收` / `伏笔埋设`
- ✅ 用具体场景描写

### F. 套路术语
- ❌ `反套路` / `套路化` / `开挂` / `主角光环`
- ✅ 直接写主角的选择和后果

### G. 角色定位 meta
- ❌ `男主角` / `女主角` / `男配 1` / `女配 2` / `男一号` / `女一号`
- ✅ 用名字 / 关系（"林老师" / "陆哥"）

### H. 文档 meta
- ❌ `设定集` / `大纲` / `节拍表` / `事件索引` / `大纲文件`
- ✅ 用"账册" / "笔记" / "外公留下的旧布"等故事内对应物

### I. 结构 meta
- ❌ `埋梗` / `铺梗` / `铺垫感` / `节奏感` / `代入感`
- ✅ 用具体动作 / 心理 / 场景

### J. 爽文 / 游戏术语
- ❌ `打脸` / `装比` / `装逼` / `爆种` / `金大腿` / `抽卡 SSR`
- ❌ `NPC` / `BUFF` / `debuff` / `增益效果` / `减益效果`
- ✅ 用现实化描写（除非是网络少年向爽文，且角色真在打游戏）

### K. 本章 / 读者 meta
- ❌ `本章要` / `本章将` / `本章末` / `本章开头`
- ❌ `读者会` / `读者一定` / `读者能感受`
- ✅ 永远不要在正文里指涉"本章"或"读者"，正文是故事不是讲解

### L. Strand Weave 系统术语
- ❌ `Strand Weave` / `Quest 主线` / `Fire 关系` / `Constellation 揭示`
- ✅ 内部规划用，不进正文

### M. 创作流程术语
- ❌ `polish_log` / `chapter_meta` / `editor_notes` / `审查报告`
- ✅ 流程层用，不进正文

## 例外（仅这些可以保留）

1. **作物种属等级**：D 级麦 / C 级豆 / B 级藤蔓 — 这是世界观内部分类术语（已在 Canon §6 锁死）
2. **<power-faction>系统级别**：一星觉醒者 / 二星凝形者 — 力量体系
3. **代码块**：``` 内的内容 H40 自动豁免
4. **blockquote**：`>` 开头的系统消息 H40 自动豁免

# H40 v3 升级  Round 23 大根治（13 路独立锐评后）

## 触发原因
13 路独立锐评（10 外部模型 + 2 子代理 + claude-opus 自读）在 22 章正文中扫到 **106 处 P0 元术语裸出**：
- 现有 28 类只覆盖 ~30%，70% 漏检
- 真实裸出包括：游戏数值面板、大纲时间戳顶头、AI prompt 残留、POV 越界、工程标书 bullet 等

## 新增 12 类（H40 v3）

### N. 大纲时间戳顶头（章节首行元数据）
- ❌ `D-30 周三 · 重生第 1 天`
- ❌ `D-13 周六 · 重生第 18 天`
- ❌ 任何 `D-N · YYYY-MM-DD` 行
- 正则：`^D-\d+\s*[·\.]\s*\d{4}-\d{2}-\d{2}`
- ✅ 改成生活化首句："醒来时窗外天还没亮，他先听见的是楼下老张烧水的壶在响。"

### O. 数值面板 / 游戏 GM
- ❌ `GM-008` / `GM-XXX` / 任何 `GM-\d+`
- ❌ `生机值 -10` / `生机值掉了` / `生机值降到 30 临界`
- ❌ `D 级 = 普通作物的 1.5 倍营养`
- 正则：`GM-\d+|生机值\s*[+\-±]?\s*\d+|生机值掉了|生机值降到`
- ✅ 改"身体感觉"："胸口被人抽走一截，腿肚子开始发软"

### P. 重生者编号系统
- ❌ `重生者 #4732` / `#4732` / `#47XX` / `#47——` 这种井号编号
- ❌ `四七三二`（汉字写法同样禁止）
- ❌ `这一系列里另外一个`这种"系列号"暗示
- 正则：`重生者\s*#\d+|#\d{4}|#47XX|四七三二`
- ✅ 系统对话外**全删**；要保留时改成"那一只手抹过的人"

### Q. 系统术语漂移（手册 vs 系统不一致）
- ❌ `这时候系统又给了一行字：`（前文一直叫"铜面具老者/手册/那个声音"）
- ❌ `系统提示`
- 正则：`系统(又)?给(了|出)一行字|系统提示`
- ✅ 用前文已建立的指代："那只铜面具又在他眼前一闪，半句话钻进脑子里"

### R. 背包系统术语
- ❌ `存储位` / `心里那个方框` / `意念调出存储位`
- ❌ `空间内立刻浮出一行小字`
- 正则：`存储位|心里那个方框|意念调出存储位|空间内立刻浮出`
- ✅ 改"空间感"："那一筐物事像沉进无波的水里，他一闭眼就再看不见。"

### S. 偷懒短语 "天然懂"
- ❌ `他天然知道` / `他天然就懂` / `这一刻天然就懂`
- 这是回避具身描写的标志
- 正则：`天然(就)?[懂知]`
- ✅ 改"试错"："他试到第三次才明白"

### T. 工程标书 bullet 体
- ❌ `附属防护结构 / 农田水利配套`
- ❌ `清表 + 平整 + 排水沟 + 应急避险窝棚`
- ❌ 任何 `X + Y + Z + W` 加号串列
- 正则：`附属防护结构|清表\s*\+\s*平整|^\s*[一-鿿]+\s*\+\s*[一-鿿]+\s*\+\s*[一-鿿]+\s*\+`
- ✅ 散文化："砖、水泥、钢筋、铁丝网、防水布，这一批是上午到的。"

### U. AI prompt / 剧本分镜词残留
- ❌ `附件是两张图。一张是货架的照片`
- ❌ `价签显示"X·X·X·促销价 18.8 元"`（AI 生图细节描述词）
- ❌ `语音四十二秒，最后五秒只有 X 的呼吸声`（剧本分镜）
- 正则：`附件是.+张图|价签显示.+促销价|分钟.+只有.+呼吸声`
- ✅ 改场景描写："<protagonist>点开<analyst-character>发来的两张图。一张是货架，原本码着大米和面粉的位置只剩两个空筐，标签还贴在原位..."

### V. POV 越界（主角不在场却描述他人私事）
- ❌ `老张那个汽修工，他爱人天天给他煮的咸粥...这两件事<protagonist>今晚都看见了`
- ❌ 主角不在场却出现"今晚都看见 / 这两件事 X 都看见"
- 正则：`今晚都看见|这两件事[<protagonist><female-lead>].+(看见|知道)`
- ✅ 改"主角想起 / 推测"："他想起老张昨夜跟他提过一句..."

### W. 大纲语气备忘录
- ❌ `今日：建材首批到，砖+水泥+钢筋+铁丝网+防水布。<antagonist>那边在桃园街铺货。<character-T>朋友圈被人放原图揭穿（非我，疑<antagonist>手笔）`
- ❌ `<antagonist-2>外勤已布棋，盯<sister-character>。<antagonist>清单外`
- ❌ 任何"疑 X 手笔" / "X 清单外" / "X 已布棋" / "外勤已"上帝视角语气
- 正则：`今日：.+<antagonist>|疑[陈秦].+手笔|已布棋|清单外|外勤已`
- ✅ 改成主角"睡前抽烟时数桥段"散文体

### X. 直念代码 ID / 网名
- ❌ `你好，nul1ptr。`（现实里直接叫别人代码网名，违和+中二）
- 正则：`nul1ptr|你好，nul`
- ✅ 改成"我在前世见过你那个 ID"或用真名

### Y. "你这一份 / 这一份"作代称
- ❌ `你这一份从今天起能感应一整片地`
- ❌ `他这一份` / `她这一份` 作模糊代称
- 正则：`(你|他|她)这一份(?![能力])`
- ✅ 改成具体本事："你这个本事" / "你这个能听见植物的本事"

### Z. "一档/半档"作量词
- ❌ `多了一档稳` / `压一档` / `档位升级`
- ❌ `一档/半档`描述能力强弱
- 正则：`多了一档|压一档|档位升级|抽了一截.+一档`
- ✅ 改成具体感："胸口又抽掉一截力气" / "比昨天稳一些"
