# 工程化语癖永久禁忌（跨项目护栏）

> 立于 Round 23（2026-05-01）
> 触发：《<example-project>·我在空间里种出了整个基地》Ch1-22 锐评诊断
> 症状：作者用"做软件项目"的方式写小说 → 读者读起来像 changelog

---

## 一、本规范要解决的问题

读者翻完前 22 章，记得 8 个画面 / 3 个笑点 / 2 个酸鼻。
而不是记得"生机值 80 + 印记 5 颗 D 级核晶 + 还剩 5 天爆发"。

---

## 二、七大工程化语癖（H41-H46 + H47 综合）

### 1. 章末账册段（H41）BLOCK
正文章末出现：
- "他翻开账册添：" / "他在账册上添了一行/笔/三个字："
- "今日：" 后接列点流水
- "DX-XX：" 紧跟列点 ≥3 项

→ 删除整段，改为画面 / 动作 / 一句对白

### 2. D-XX 倒计时顶头（H42）WARN
正文章首前三段出现：`D-\d+ · 2026-\d+-\d+ 周.`

→ 全卷 ≤ 8 次。其他改为自然时间感（"天亮得比昨天早一点。" "立夏过了两天。"）

### 3. 设定面板（H43）BLOCK
单独成行的：
- `> "X 级\w+：营养 ×\d"`
- `> "本日空间存储：用量 0\.\d+ m³ / 上限 \d+ m³"`
- `> "残篇 \d+/9 解锁。"`
- `> "印记升阶：[一-龟]+ → [一-龟]+。条件：\d+ 颗 \w 级核晶"`
- `生机值[：:]\s*\d+` 单独成行

→ 完全感受化，禁止任何"游戏 UI / 程序日志 / 产品规格" 表述

### 4. 模板对白高频（H44）WARN
单章独立成行的"中。""得味。""晓得。""嗯。" 任一词 ≥ 5 次

→ 用动作 / 表情 / 上下文替代

### 5. NPC 数量爆炸（H45）WARN
卷一前 22 章累计有名 NPC > 10 人

→ 推迟 / 删除 / 浮光掠影化

### 6. 烟火气缺失（H46）WARN
单章正文中具象食物描写 + 具象邻里街景动作两者同时为 0

→ 强制每章 ≥ 1 处具象食物 + ≥ 1 处具象邻里

### 7. todo list 句式（H47 新增）WARN
"今天三件事：A + B + C" / "明天两件事：1. … 2. …" / "今天起做第一件事 / 第二件事 / 第三件事" 模板句

→ 删除。改为按场景自然推进，让读者从动作里看出主角"今天有几件事要做"

## 三、自检清单（每章定稿前必过）

- [ ] 章末没有"翻开账册" 段
- [ ] 章首没有"D-XX · 周.· 重生第 X 天" 标头（除节点章）
- [ ] 没有任何 `> "X 级 / X/9 / X m³ / 生机值 XX"` 单独成行
- [ ] 单章"中。""得味。""晓得。" 单词独立成行各 ≤ 4 次
- [ ] 本章没有引入新 NPC（如果引入，记账确认未超本卷上限）
- [ ] 本章 ≥ 1 处具象食物 + ≥ 1 处具象邻里 / 街景
- [ ] 本章末没有"X 天。" 单独成行倒计时
- [ ] 本章没有"今天三件事 / 两件事 / 五件事 / 今天起做第一件事" 模板句
- [ ] 设定升级写成"感受 / 天然就懂"，不用"系统提示"

## 五、底层心法

**读者要的是烟火气、人情味、饿和饱、笑和哭。**
**读者不要 changelog。**

写完一章后问自己：
- 这一章如果删掉所有数字 / 倒计时 / 系统提示 / 列点 / 账册段，故事还在吗？
- 如果不在 = 你写的是设定文档，不是小说
- 如果在但变弱了 = 那些数字是工程师拐杖，丢掉它，你的小说才能站起来
- 如果在且更好了 = 这一章对了
