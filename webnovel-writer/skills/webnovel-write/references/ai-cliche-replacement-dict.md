## 北极星：消除"AI 写出来"的痕迹

13 路独立锐评一致：本项目当前正文有强烈的"AI 文风"特征。
这些特征不是某一句的问题，而是**跨章累计 270+ 处**的句式重复。

任何一类超过单章配额 = 立刻替换。

## 核心 13 类禁用 / 限用句式

### 禁用 0 配额（出现即替换）

#### 1. "天然知道 / 天然就懂"
```diff
- 他天然知道沙漏每查一次少一格。
+ 他试着想"妹妹叫什么"——沙漏纹丝不动。再试"妹妹什么样"——还是不动。这一刻他才明白：已经知道的不收费。

- 他天然就懂——心里那个方框装东西按实在体积算。
+ 他试着抓"全部"——五箱罐头一起进去了。又试着抓单只——也行。再试加超出空间体积的木箱——抓不进。试到第三次他懂了。
```

#### 2. "你这一份 / 这一份" 作模糊代称
```diff
- 你这一份从今天起能感应一整片地。
+ 你这个能听见植物的本事，从今天起能听一整片地。

- 他这一份只在他和老柱、林老师离他不远的时候连得最稳。
+ 他和老柱、林老师之间那条看不见的线，离得近时最稳。
```

#### 3. "X 秒。也许 X 秒。"
```diff
- 三秒。也许四秒。
+ （删一句，留一个具体时间或删全部）
+ 他没数。等他抬眼时，街口那盏路灯已经熄了。
```

### 限用配额（单章超出即替换）

#### 4. "X 笑了一下" — 单章 ≤2 次
**全卷当前命中**：65 处（Ch8/Ch11/Ch14/Ch16/Ch17/Ch18/Ch19/Ch20 重灾）

**多样化替换库**（按情境分类）：

```
情境：尴尬笑   → 嘴角动了动 / 没真笑出来 / 扯了扯嘴角
情境：苦笑     → 喉头动了一下 / 鼻腔出了一声短气
情境：暖笑     → 眼角软了 / 看着她，眼神里多了一层东西
情境：冷笑     → 嘴边那一勾没收回 / 露出一颗虎牙
情境：意会笑   → 两人对了一眼 / 没说话，都点了一下头
情境：自嘲笑   → 摇摇头 / 自言自语了一句什么
```

#### 5. "他点头 / X 点头" — 单章 ≤3 次
**全卷当前命中**：53 处（Ch12/Ch19/Ch20 重灾）

**多样化替换库**：

```
答应     → "嗯"（保留少量）/ "好"（直接动作） / "我知道了"
理解     → "我懂"
确认     → "是" / "对" / "没错"
带动作   → 点了下头，站起来 / 应了一声，转身去厨房 / 抬眼看了看，没再说什么
```

#### 6. "嗯。" 单字段 — 单章 ≤8 次（现 30+）
**改写策略**：
- 保留少量真实"嗯"（情侣/兄妹温情时刻）
- 多数改成有内容的回应：

```diff
- "嗯。"
- "嗯。"
- "嗯。"
+ "嗯。"
+ <antagonist>继续喝他那盏酒，吃了一口刺身。
+ "陆哥，这家店你以前来过吗。"
+ "前世来过两次。"
```

#### 7. "中。" 单字段 — 单章 ≤4 次
**老柱口头禅**，保留少量本地化味道但不能成模板。
```diff
- "中。"
- "中。"
+ "中。"
+ 老柱抹了一把脸上的土，弯腰拎起袋子。
+ "陆哥，今晚北麓那段我盯。"
```

#### 8. "印记跳了一下" / "印记温了" — 单章 ≤2 次
**全卷当前命中**：15 处（几乎每章）

**多样化替换**：
```
冷暖    → 手心一暖 / 掌心凉了一下 / 那块印从皮肤底下抽了一下
方向    → 烙印朝东南那个方向轻轻顶了一下 / 烙印的边缘像有人按了一下
节奏    → 印记慢半拍 / 印记跳得比昨天紧 / 印记没动，安静得像在等
危险    → 印记一下子绷紧 / 印记两档叠跳
```

#### 9. "在心里 X X X" — 单章 ≤2 次
**全卷当前命中**：14 处（Ch9 重灾 4 次）

**改写策略**：
```diff
- 他在心里把这一阵闷压下去。
+ 他没再往下想。

- 他在心里给自己拉了一条线：今后任何一次催化，生机值不低于 30。
+ 他给自己定了一条规矩——下次催，留一截力气。

- 他在心里点了一下另外一件事。
+ 还有一件事他没忘。
```

#### 10. "不是 X，是 Y" 二元否定肯定 — 单章 ≤2 次
**全卷当前命中**：9 处

**改写策略**：直接改正面陈述
```diff
- 不是哭。是这一刻他终于让自己承认：他孤身一人。
+ 他没哭。但他知道自己一个人扛着。

- 那不是声音，是一种天然的知道。
+ （彻底重写，去掉"天然的知道"）
+ 像皮肤底下有人轻轻敲了一下，他自己说不上是听见还是感觉到。
```

#### 11. "X 的瞳孔 / 呼吸 / 脸色 X 了一下" — 单章 ≤1 次
**全卷当前命中**：6 处（Ch13/Ch19 重灾）

**改写策略**：换具体动作
```diff
- <analyst-character>的瞳孔缩了一下。
- <analyst-character>的呼吸停了一拍。
- <analyst-character>的脸色白了一下。
+ <analyst-character>的手指停在键盘上没动。
+ 他喉头滚了一下，没说话。
+ 他的咖啡杯歪了一下，杯沿那一截咖啡漫到桌面。
```

#### 12. "他不答 / 她什么都不问" — 单章 ≤1 次
**改写策略**：用动作和场景填空白
```diff
- 他不答。
- 她什么都不问。
+ <protagonist>端起茶杯，水已经凉了。<female-lead>低头收拾桌上那张请假条。窗外有自行车铃响过两下，没人接茬。
```

#### 13. "他脚步停了一下 / 顿了一下 / 顿了顿" — 单章 ≤2 次
全卷高频，常用于"突然反应"，过度使用会成模板。
```diff
- <protagonist>脚步停了一下。
+ <protagonist>走出半步又回头。
```
